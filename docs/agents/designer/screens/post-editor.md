# 글쓰기 (에디터)

## 레이아웃
- 상단바: 카테고리 선택 드롭다운, 공개범위 토글(전체/이웃공개/비공개), "임시저장"(ghost) / "발행"(primary) 버튼
- 제목 입력(대형 손글씨 placeholder "제목을 입력하세요")
- `RichEditor`: 텍스트 서식 툴바 + 이미지 드래그앤드롭 업로드
- 하단: 태그 입력(콤마/엔터로 TagChip 생성)

## 주요 인터랙션
- 30초 간격 자동 임시저장(로컬스토리지 + 서버 DRAFT 동기화), 저장 시 상단에 "n초 전 자동저장됨" 은은한 텍스트
- 발행 클릭 시 확인 모달(WatercolorCard 팝업) — 공개범위 재확인

## 엣지 케이스
- 이미지 업로드 실패: 해당 이미지 자리에 ErrorState 인라인 + 재업로드 버튼
- 제목/본문 미입력 상태로 발행 시도: 인라인 에러(shake) + 포커스 이동
- 페이지 이탈 시 저장 안 된 변경사항 있으면 브라우저 confirm 경고
