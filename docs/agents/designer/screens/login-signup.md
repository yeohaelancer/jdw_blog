# 로그인 / 회원가입

## 레이아웃
- 중앙 정렬 `WatercolorCard`(max-width 420px), 배경은 `--color-bg-wash` 전체 적용
- 상단: 손글씨 폰트 로고 "물빛 다이어리"
- 로그인: 이메일/비밀번호 입력 + `AppButton(primary)` "로그인" + 하단 "회원가입" 텍스트 링크
- 회원가입: 이메일/닉네임/비밀번호/비밀번호 확인 + 이메일 중복확인 버튼(인라인, ghost variant)

## 주요 인터랙션
- 이메일 중복확인: 입력 blur 시 자동 체크 → 통과 시 입력창 우측에 초록 체크(수채화 브러시 stroke 애니메이션)
- 비밀번호 규칙: 8자 이상, 영문+숫자 조합 — 실시간 강도 표시(약함/보통/강함, 색상+텍스트 동시 표기)
- 로그인 성공 시 블로그 홈으로 fade+slide 전환

## 엣지 케이스
- 로그인 실패(비밀번호 불일치): 카드 shake 애니메이션 + `--color-error` 텍스트 "이메일 또는 비밀번호가 올바르지 않습니다"
- 이메일 중복: 입력창 하단 에러 텍스트 + 아이콘
- 네트워크 오류: 카드 내부 ErrorState(illustration='network') + 재시도 버튼
- 로딩 중: 로그인 버튼 loading 상태(스피너), 중복 클릭 방지
