# 블로그 홈 (피드)

## 레이아웃
- 상단: 블로그 커버 이미지(수채화 프레임) + 프로필(`Avatar lg`) + 블로그명(Heading) + 소개글
- 좌측 사이드바(데스크톱만): `CategoryTree`, 태그 클라우드(`TagChip` 목록, 빈도 비례 크기)
- 메인: `PostCard` 그리드 — 모바일 1열 / 태블릿 2열 / 데스크톱 3열, 무한스크롤(하단 도달 시 다음 페이지 로드)
- 우상단: "글쓰기" `AppButton(primary)` (본인 블로그일 때만 노출)

## 주요 인터랙션
- 카테고리 클릭 → 해당 카테고리 게시글만 필터(URL 쿼리 반영), CategoryTree 활성 항목 하이라이트
- 태그 클릭 → 태그 필터 적용
- PostCard 클릭 → 게시글 상세로 이동 (카드 클릭 시 살짝 확대되는 hover 트랜지션)

## 엣지 케이스
- 게시글 없음: `EmptyState(illustration='post')` "아직 작성된 글이 없어요"
- 로딩 중(무한스크롤): 카드 3개 스켈레톤(수채화 wash 애니메이션 shimmer)
- 비공개/이웃공개 글은 목록에서 권한 없는 사용자에게 노출 안 됨(백엔드 필터링 전제)
