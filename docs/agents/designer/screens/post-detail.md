# 게시글 상세

## 레이아웃
- 상단: 카테고리 `TagChip` + 제목(Heading 32px) + 작성자 Avatar/닉네임/작성일 + 조회수
- 본문: `WatercolorCard` 내부에 렌더링된 리치텍스트(이미지 포함), 이미지는 웹툰 컷처럼 얇은 테두리
- 하단: 태그 목록 → `LikeHeart`(큰 사이즈, 중앙 정렬, 클릭 시 파티클) → 댓글 영역

## 댓글 영역
- 댓글 입력창(하단 고정, 비밀댓글 체크박스) → 목록: `SpeechBubbleComment` 리스트(최신순), 대댓글은 들여쓰기
- 댓글/대댓글 작성 직후 목록 상단(또는 부모 하위)에 fade-in 삽입

## 엣지 케이스
- 비공개 글 접근 권한 없음: 전체 화면 ErrorState "비공개 게시글입니다"
- 댓글 없음: 댓글 영역에 EmptyState(illustration='comment') "첫 댓글을 남겨보세요"
- 좋아요 API 실패: LikeHeart 낙관적 업데이트 롤백 + toast "잠시 후 다시 시도해주세요"
- 삭제된 댓글(대댓글 있음): "삭제된 댓글입니다" 처리, 대댓글은 유지
